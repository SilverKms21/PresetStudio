🎛️ Preset Studio — Universal JSON Preset Manager🇧🇷 Leia em PortuguêsPreset Studio is a cross-platform desktop application (Linux and Windows) built with Python and Tkinter to create, edit, validate, and preview .json preset files. It features full native support for Filmcraft (filmcraft.effect-presets), alongside a universal mode compatible with any software that relies on JSON configuration files (such as OBS, EasyEffects, Godot, and more).✨ Key FeaturesReal-Time NLE Preview Viewer:Animated playback with speed multiplier (1x to 100x), loop toggle, frame-by-frame stepping (← / →), and keyframe jumping (Ctrl + ← / Ctrl + →).Interactive on-screen gizmos to animate Position, Scale, and Rotation directly in the viewport.Action Safe (95%) and Title Safe (90%) guides, anchor point overlay, and switchable backgrounds (Dark Monitor, Transparency Grid, Chroma Green).Built-in test primitives (Sample Text, Rectangle, Square, Circle, Triangle, Diamond, and Star).Native Filmcraft Support:Ready-to-use templates for text/subtitle effects (graphic_text) and motion transforms (motion).Automatic proportional coordinate rescaling (position and anchor) when changing base canvas resolution.Visual keyframe editor supporting AutoBezier, ContinuousBezier, Linear, and Hold interpolation curves.3 Synchronized Workspace Views:Inspector & Viewer: Visual parameter editing with RGBA color pickers and keyframe diamonds.JSON Tree: Hierarchical tree editor for any generic JSON schema.Raw JSON Code: Direct code editor with auto-formatting and schema validation.Safety & Multi-App Profiles:Automatic .json.bak backup creation before overwriting saved files.Custom directory profiles per application.🚀 Getting StartedPrerequisitesPython 3.8+ with tkinter support.Ubuntu/Debian/Mint: sudo apt install python3-tkFedora/Nobara: sudo dnf install python3-tkinterWindows: Included by default in the official Python installer.Running from Sourcegit clone https://github.com/your-username/preset-studio.git
